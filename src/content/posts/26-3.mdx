## Upcoming changes for server owners

We are currently in the process of preparing a config merge, so that almost all of the config options currently split across the various Bukkit, Spigot, and Paper files finally go together. Our current plan is for this to land in the next major release, aka 26.4. You can track the current progress and changes here: https://github.com/PaperMC/Paper/issues/14304

---

## Faster CI build times and deployment

[Namespace](https://namespace.so/github-actions/?utm_source=oss&utm_campaign=papermc) are now sponsoring our CI runners! A lot of waiting time on Minecraft releases and commits in general came down to slow CI, and TeamCity configuration editing was also a fairly slow process whenever we moved or created version branches.
With the switch, deployment of builds, API, and dev bundles has become significantly faster, and with our own efforts in parallel, has simplified internal processes around updating to new Minecraft versions.

In the future, we also plan on making produced JAR files more tamper-proof, e.g. by signing them. The pull request workflows will also be made faster later.

Next to the above, we have also decreased the distributed JAR file size by about 10mb!

## For developers

A lot of API that was previous marked as experimental, including most of the data component API, have had their experimental annotations removed!

### Events for working with cushions

We introduced [EntityBreakEvent](https://jd.papermc.io/paper/26.3/io/papermc/paper/event/entity/EntityBreakEvent.html) and [EntityBreakByEntityEvent](https://jd.papermc.io/paper/26.3/io/papermc/paper/event/entity/EntityBreakByEntityEvent.html), similar to the existing hanging break events. Next to that, you can use the pre-existing [EntityPlaceEvent](https://jd.papermc.io/paper/26.3/org/bukkit/event/entity/EntityPlaceEvent.html).

## Other changes and additions

Here is a selection of other notable additions since the last major update post:

### API

- Player post-processing effects can be viewed and modified via [Player#postEffects](<https://jd.papermc.io/paper/26.3/org/bukkit/entity/Player.html#postEffects()>)
- [Mob#setDespawnInPeacefulOverride](<https://jd.papermc.io/paper/26.3/org/bukkit/entity/Mob.html#setDespawnInPeacefulOverride(net.kyori.adventure.util.TriState)>) is no longer deprecated and functions again
- [EntityConstructEvent](https://jd.papermc.io/paper/26.3/io/papermc/paper/event/entity/EntityConstructEvent.html) is fired when entities such as golems or the Wither are created from block patterns
- [EntityCollideWithEntityEvent](https://jd.papermc.io/paper/26.3/io/papermc/paper/event/entity/EntityCollideWithEntityEvent.html) allows controlling entity pushing
- Sulfur Cube item swallowing can now be controlled via [SulfurCube#swallow](<https://jd.papermc.io/paper/26.3/org/bukkit/entity/SulfurCube.html#swallow(org.bukkit.inventory.ItemStack)>) and [SulfurCubeSwallowItemEvent](https://jd.papermc.io/paper/26.3/io/papermc/paper/event/entity/SulfurCubeSwallowItemEvent.html)
- [CreakingHeart](https://jd.papermc.io/paper/26.3/org/bukkit/block/CreakingHeart.html) now contains its Creaking entity and allows setting or spawning its protector
- [PlayerCodeOfConductSendEvent](https://jd.papermc.io/paper/26.3/io/papermc/paper/event/connection/configuration/PlayerCodeOfConductSendEvent.html) allows modifying the Code of Conduct sent to individual players
- The Vanilla reason an entity was removed can now be queried via [Entity#getRemovalReason](<https://jd.papermc.io/paper/26.3/org/bukkit/entity/Entity.html#getRemovalReason()>) and [RemovalReason](https://jd.papermc.io/paper/26.3/io/papermc/paper/entity/RemovalReason.html)

#### Deprecations

- [PlayerAnimationEvent](https://jd.papermc.io/paper/26.3/org/bukkit/event/player/PlayerAnimationEvent.html) has been deprecated in favor of [PlayerArmSwingEvent](https://jd.papermc.io/paper/26.3/io/papermc/paper/event/player/PlayerArmSwingEvent.html)
- [PotionEffectTypeCategory](https://jd.papermc.io/paper/26.3/org/bukkit/potion/PotionEffectTypeCategory.html) has been deprecated in favor of [PotionEffectType.Category](https://jd.papermc.io/paper/26.3/org/bukkit/potion/PotionEffectType.Category.html)
- [PotionBrewer](https://jd.papermc.io/paper/26.3/org/bukkit/potion/PotionBrewer.html) have been now deprecated given they have been data-driven, see [BrewingRecipe](https://jd.papermc.io/paper/26.3/org/bukkit/inventory/BrewingRecipe.html)

### Reminder: Versioning change

We have replaced the old `-R0.1-SNAPSHOT` suffix with a much more informative versioning scheme. See [the 26.1 announcement](https://papermc.io/news/26-1/) for more information.
